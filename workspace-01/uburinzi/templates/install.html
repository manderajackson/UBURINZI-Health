For patients, nothing to install. They receive ordinary SMS (and WhatsApp or a voice call if they go quiet) on the phone they already own. This page is about putting the clinic dashboard on your own phone or the nurse's phone.

Android (Chrome, Edge, Samsung Internet)

  1. Open this site in Chrome.
  2. Tap the ⋮ menu (top right).
  3. Tap “Install app” or “Add to Home screen”.
  4. Confirm — the Uburinzi icon appears on your home screen and opens full-screen.

On most phones a button labelled “⬇ Install on this phone” appears by itself in the left-hand menu — tap it and you're done.

It also works offline: pages you have already opened (patient list, alert queue) still load with no data, and anything you do is queued until the connection returns.

iPhone / iPad (Safari)

  1. Open this site in Safari (not Chrome — iOS only allows Safari to install).
  2. Tap the Share button (box with an up arrow).
  3. Scroll down and tap “Add to Home Screen”.
  4. Tap Add — the icon appears with the other apps.

iOS refreshes the icon badge for open alerts each time you open the app.

Run it on your own computer or server

Everything you need is one download away — no cloud account required.

# 1. download and unzip # 2. in the folder: python3 -m venv .venv && source .venv/bin/activate # Windows: .venv\Scripts\activate pip install -r requirements.txt python -m app.cli reset # creates the DB + demo cohort python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 # then open http://localhost:8000 → founder@uburinzi.rw / uburinzi2026

Before you put real patients on it

  • Deploy it somewhere with HTTPS (see the deployment guide).
  • Add your Africa's Talking credentials on Channels.
  • Paste the six webhook URLs into the AT dashboard.
  • Get the protocols and Kinyarwanda copy signed off by your clinical advisor.
  • Capture consent per patient before the first message goes out.
