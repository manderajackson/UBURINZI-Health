How patients answer

{% if store.reply_channel == 'ussd' %} This deployment uses USSD for replies, so check-in messages tell patients to dial the code instead of replying by SMS. {% else %} Replies are expected by SMS. In Rwanda, Uganda, Bangladesh, Thailand, Vietnam and Japan an A2P SMS cannot be answered — switch to USSD (or a short code) or replies will never arrive. {% endif %}

With USSD selected, the “Reply 1=Yes, 2=No” tail is replaced by the dial instruction in every check-in, in the patient's own language, kept inside one SMS segment. Webhook: /api/webhooks/ussd

Escalation policy

When a flagged patient stops answering SMS, Uburinzi retries on WhatsApp, then calls them. Only amber/red patients are escalated, never more than the caps below.
